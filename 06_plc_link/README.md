# 06 — PLC link

The assessment asks to show a PLC tag changing when an object is detected. This package includes a local tag simulator only; no PLC protocol or physical controller is connected.

For real proof, document PLC make/model, protocol (e.g. Modbus TCP or OPC UA), tag address/type, network boundary, read/write permissions, and a video/screenshot of the tag changing during a real detection. Test safe states with the controls engineer.
